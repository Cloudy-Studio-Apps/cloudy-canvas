# File Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Several files open at once on desktop as tabs in a custom title bar, where only the tab on screen draws, background tabs keep as little in memory as the spec allows, and each agent (MCP session) is bound to one tab.

**Architecture:** A plain-TS tab model (`src/canvas/tabs/`) owns each tab's `CanvasDocument` and state (hibernated / document / headless / active) and applies the memory policy. The router stays: a file route (`/board/:id`, `/design/:id`) means "open or activate that tab", every other route is the Home tab, so every existing `navigate(...)` keeps working. A React tab host (`src/canvas-ui/tabs/`) mounts the editors of headless and active tabs (headless ones hidden, inert and with the engine suspended); editors take their document from the tab instead of loading it. Agent sessions bind to tabs in `src/app/mcp/`.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`), React 19, React Router, Zustand (UI state only), Yjs through `CanvasDocument`, Tauri 2 window APIs, Radix through `@shared/ui/kit`.

**Spec:** `docs/superpowers/specs/2026-11-09-file-tabs-design.md` (read it before any task; the tables in "Tab states and memory" are the policy).

## Global Constraints

- Root `CLAUDE.md` rules apply to every task; read the README of every folder you touch and update it in the same task when behavior changes. New folders whose behavior needs explaining get a README.
- **No test framework.** Every task's verification is `pnpm lint`, `pnpm typecheck` and `pnpm format:check`, all passing. Don't run `tauri dev`, cargo, builds or browsers.
- Layering: `src/canvas/tabs/` is plain TS (no React, no `@platform`, no products); `src/canvas-ui/tabs/` is React and never imports products; products are wired in from `src/app/`.
- Types in sibling `.types.ts` files; small single-purpose files (~200 lines max); ids from `createId()`.
- Zustand never holds documents or engines; the tab model is a `Store` (`canvas/utils/store.ts`) read in React with `useSyncExternalStore`.
- User-facing text through each folder's `t` with `locales/en.json` and `locales/es.json`; MCP tool text stays English.
- Semantic tokens only, radii 4px controls / 6px menus, no pills. Use kit components (`IconButton`, `DropdownMenu`, …); raw `<button>` needs the `bespoke:` eslint comment.
- Desktop means `isTauri() && !isAndroidPlatform()` (the test `projectsSupported()` already uses). Export it once as `tabsSupported()` from `src/platform/` and use only that.
- Memory constants, exact starting values: grace after leaving a tab **30 s**; agent counts as calling for **2 min** after its last call; **5** most recent tabs and **10 min** unused before hibernating; at most **3** headless engines; **10** closed tabs remembered.
- Commits on master, no `Co-Authored-By` line (user preference). One commit per task, `feat(tabs): …` / `refactor(tabs): …`.
- The last task adds the changelog entries (`CHANGELOG.md` and `CHANGELOG.es.md`, under the unreleased `New`/`Novedades`), never naming third-party products.

## Review Focus

1. **Closing or hibernating a tab with pending autosave** must flush first: a tab whose autosave is pending (1.5 s debounce) must never lose its last edits when it drops to document state, hibernates, or closes. Task 6 and Task 9 own this; their reviewers check the flush path explicitly.
2. **A hosted live session survives its tab leaving the screen**: hosting a file, switching to another tab for minutes, then back must leave guests connected and their edits saved. Task 10 owns the doc-level autosave and decoupling `useHostedFile`'s unmount stop.
3. **Opening the same file twice** (Home card, OS double-click, agent `open_design`, a `cloudy-canvas://` link) must activate the existing tab, never load a second document for the same file id. Task 2 (`open` reuses by `fileId`) and Task 4 (route sync) own it.
4. **Agent calls during an engine rebuild**: an agent call on a tab in document state must wait for the headless engine (up to the existing 15 s `waitFor` timeout) and then run, never run against a destroyed engine or the user's active tab. Task 13 owns it.
5. **Keyboard focus in background tabs**: a headless editor must take no keys or pointer events (shortcuts like Delete must only reach the active tab's engine). Task 5 owns `inert` + `setSuspended`.

**Interfaces:**

- Produces (exact names; later tasks rely on them):
  ```ts
  type TabState = "hibernated" | "document" | "headless" | "active";
  type TabLoad =
    | { status: "idle" }
    | { status: "loading" }
    | { status: "ready"; document: CanvasDocument; info: FileInfo | null }
    | { status: "error"; message: string };
  interface FileTab {
    readonly id: string; // createId()
    readonly type: FileType; // "board" | "design"
    readonly fileId: string; // storage id, or "live:<fileId>" for a joined session
    readonly name: string;
    readonly params: Readonly<Record<string, string>>; // the route's search params at open (dir, project, libraries, starter, mode)
    readonly live: ShareGuest | null;
    readonly state: TabState;
    readonly load: TabLoad;
    readonly unsaved: boolean; // changes nothing will save, or an autosave pending
    readonly hosting: boolean; // this tab shares a live session
    readonly agents: readonly string[]; // bound agent session keys
    readonly lastActiveAt: number;
    readonly lastAgentCallAt: number | null;
  }
  interface FileTabsSnapshot {
    readonly tabs: readonly FileTab[];
    readonly activeId: string | null;
  } // null = Home
  interface TabSource {
    type: FileType;
    fileId: string;
    params?: Record<string, string>;
    live?: ShareGuest;
    name?: string;
  }
  interface TabLoader {
    load(
      fileId: string,
      live: ShareGuest | null,
    ): Promise<{ document: CanvasDocument; info: FileInfo | null }>;
  }
  interface FileTabsOptions {
    loaders: Record<FileType, TabLoader>;
    maxFileTabs?: number;
    now?: () => number;
  }
  class FileTabs {
    constructor(options: FileTabsOptions);
    readonly store: Store<FileTabsSnapshot>;
    open(source: TabSource, options?: { activate?: boolean }): FileTab; // reuses the tab with the same fileId; with maxFileTabs 1 it closes the other file tab
    activate(id: string | null): void;
    close(id: string): void; // destroys its document; remembers it for reopen
    reopenClosed(): FileTab | null; // last 10 closed, this session only
    move(id: string, index: number): void;
    get(id: string): FileTab | undefined;
    byFileId(fileId: string): FileTab | undefined;
    patch(
      id: string,
      patch: Partial<Pick<FileTab, "name" | "unsaved" | "hosting" | "params">>,
    ): void;
    setState(id: string, state: TabState): void; // "hibernated" destroys the document and sets load idle
    ensureLoaded(id: string): Promise<CanvasDocument>; // loads once; concurrent calls share one promise
    bindAgent(id: string, session: string): void;
    unbindAgent(session: string): void;
    noteAgentCall(id: string): void;
    dispose(): void;
  }
  ```
- `activate` sets `lastActiveAt` on the tab being left and the tab entered, and puts the entered tab in `active` (loading it if needed). In Phase 1 the tab being left goes to `headless` (Task 9 adds the policy).

**Files:**

**Interfaces:**

- Produces:
  - `TAB_LIMITS = { leaveGraceMs: 30_000, agentActiveMs: 120_000, recentTabs: 5, hibernateAfterMs: 600_000, maxHeadless: 3 } as const`
  - `targetState(tab: FileTab, ctx: PolicyContext): TabState` where `PolicyContext = { activeId: string | null; now: number; recentRank: number /* 0 = most recent */ }` — the spec's table, first match wins:
    1. active → `active`
    2. left less than 30 s ago → `headless`
    3. an agent bound and `now - lastAgentCallAt < 2 min` → `headless`
    4. agent bound, or `hosting`, or `live`, or `unsaved` → `document` (never hibernated)
    5. `recentRank < 5` or `now - lastActiveAt < 10 min` → `document`
    6. otherwise → `hibernated`
  - `evaluate()` then enforces the 3-headless cap by demoting the least recently active non-agent-calling headless tab first, then the least recent agent one.
  - Restored-and-never-clicked tabs are `hibernated` (no document).
