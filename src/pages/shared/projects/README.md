# Shared project pieces

_Used by the Projects page and the project home. Import them from `@pages/shared/projects`, never from another page's folder._

- **`ProjectIcon`:** a project's mark, its picture or its initials (`projectInitials`) on its color (`PROJECT_COLORS`, `randomProjectColor` pick a new project's color).
- **Images:** `writeProjectImage(root, "icon" | "cover", image)` copies a picked image to `.cloudy/<kind>.<ext>` and returns the file name the manifest keeps; `useProjectImage(root, file, rev)` reads it back as a URL and `useImageUrl` makes one from bytes.
- **`useProjectFileCount(root, enabled)`:** how many boards and designs a project holds.
- **Libraries' colors:** `libraryColors(records, max)` (the color variables' default values, aliases followed), `useProjectLibraryColors(root, id, enabled)` (the project's first library's colors, read from its `.clib`, for the Projects page's card swatches) and `LibraryStrip` (colors side by side, sized by its `className`; the project home's sidebar, cards and cover).
- **Styles to start a library from:** `firstLibraryRecords(source, taken?)` (a `FirstLibrarySource`: nothing, a `.cdesign`/`.cboard`'s records through `readFileTokens`, or a tokens JSON through the variables module's `readTokenSource`; a file's records are a copy: those tagged with a library, and those whose id is in `taken`, the ids the project's other libraries hold, get new ids through `copyLibraryRecords`, and all come back untagged, so one id is never in two libraries), `copyLibraryRecords(records, renew?)` (new ids for the records `renew` picks, all by default, and their axes' modes, wherever they appear; untagged), `pickStylesSource(kind, labels)` (asks for the file and reads it at once, so one with nothing to give is flagged) and `librarySourceOf(styles)`; the New project and New library dialogs use them.
