# Files

_How it works. The rules are in the root [CLAUDE.md](../../../CLAUDE.md)._

## Files

- **Files:** every product's files go through `canvas-ui/file/`: `useCanvasFileLoader(id, { noun, open, create })` loads the `CanvasDocument` from `Storage` (or starts an empty one for a new id), `useCanvasFileSaver(id, engine, info, format)` saves it (a `CanvasFileFormat`: file type, noun, untitled name, `encode`) and is provided as `CanvasFileContext` (`useCanvasFile()`, read by `SaveIndicator` and `DocumentInfoPopover`, also in `canvas-ui/file/`), and `useCanvasThumbnail` takes the preview. A file is a 4-byte magic, a u32 format version and a Yjs update (`encodeCanvasFile`/`decodeCanvasFile`, `canvas/file/`): `CCBD` for `.cboard` (`products/board/file/board-file.ts`; the board's wrappers are `useBoardLoader`, `useBoardSaver`, `BOARD_FILE_FORMAT` in `products/board/ui/file/`), `CCDS` for `.cdesign` (`products/design/file/design-file.ts`, `useDesignLoader`, `DESIGN_FILE_FORMAT`). `TauriStorage` keeps a recent-files index (id → path) in the app data folder. Ctrl+S / Ctrl+Shift+S are engine commands that run the host's handlers (`engine.handleHostAction("save", …)`).
  - **Autosave** (`useCanvasAutosave`, driven by `useCanvasFileSaver`): 1.5 s after changes stop (at most every 10 s while editing), and once more when the editor closes. A board with no file is autosaved as a **draft** (`storage.saveDraft`: `<appData>/drafts/<id>.cboard`, `FileInfo.draft`, badged on Home); Save asks where to put it and the draft file is removed (`storage.save`), forgetting a draft deletes it, and clearing the recents keeps drafts. Revisions counted per change keep the board dirty when it changes mid-save. The top bar's `SaveIndicator` shows a cloud while saving and a checked cloud for 3 s after (`saved` in the file context); the unsaved dot shows only when autosave is off or failed. The setting is `shared/stores/autosave-store.ts` (on by default, Settings › Files & storage). Closing the window waits for the tasks set with `appLifecycle.onBeforeQuit` (`AppLifecycle` in `shared/core`, `platform/tauri-app-lifecycle.ts`, up to 5 s; it needs `core:window:allow-destroy`): pending autosaves are flushed. Home's previews are pictures of each file (`useCanvasThumbnail(id, engine, saved)`: `engine.thumbnail`, only when the document changed since the last one, taken after a manual save, when the quit dialog opens and as the editor's `onClose` task and a quit task (skipped when already taken); it returns `capture`, stored with `storage.saveThumbnail` in `<appData>/thumbnails/<id>.jpg`, removed when the file is forgotten); `useFileThumbnail` (`pages/home/`) loads them and reloads when `thumbnail-store` bumps the file's version. Saves pass the document's title and description to `storage.save`/`saveDraft` (`FileMeta`), so the recents show them (a draft is named by its title); the file's name opens `DocumentInfoPopover` to edit them.
  - The index is validated on read (`isFileInfo`), written atomically (temp file + rename) and edited one change at a time (`mutate`); an unreadable one is set aside as `recent-files.corrupt.json` (`storage.takeIndexReset()`). Saves are atomic too.
  - `useRecentFilesStore` holds the recents and the ids of `missing` files (re-checked on window focus), plus `open(path)`, `relocate(id)` and `forget(id)`. Home's cards show missing files with Locate… / Remove, and every card has a ⋯ and right-click menu (`use-file-actions.ts`).
  - Files dropped on the window, picked with "Open with" or passed on the command line arrive through `FileOpenRequests` (`shared/core`, `platform/tauri-file-open-requests.ts`; drops come as `FileDrop`: `DroppedFile`s read on demand plus the client point) and are opened by `app/open-requests/`, which asks first when the open editor is dirty (`unsaved-changes-store`, set by `useCanvasFileSaver`).
  - **Quitting asks** (`CloseFileGuard`, `canvas-ui/file/close-dialog/`, mounted by the file sessions, not live guests): the window's ✕ (`appLifecycle.onCloseRequest`; the updater's `runQuitTasks` doesn't ask) opens `CloseFileDialog`: Quit · Cancel, or, with changes nothing will save (autosave off or failing), Save and quit · Quit without saving · Cancel (`file.save()` returns whether it wrote). It takes the preview (`capture`) as it opens. Leaving the editor inside the app (Back to home) doesn't ask; the preview is the editor's `onClose` task. `cloudy-canvas://` links (the deep-link plugin, scheme in `tauri.conf.json`; installers and the Arch desktop entry register it, dev builds and the AppImage register it at startup) arrive through `AppLinks` (`shared/core/app-links/`, `platform/tauri-app-links.ts`) and are read by `parseAppLink`: `open?path=<file>`, `board/<id>` / `design/<id>` (a recent file), `new/board` / `new/design`, `home`, `settings`; `app/open-requests/open-app-links.ts` follows them. A drop without a `.cboard`/`.cdesign` goes to the open editor's target in `file-drop-store` (registered by `useCanvasFileDrop(engine)` in `canvas-ui`), which adds the files to its canvas.
