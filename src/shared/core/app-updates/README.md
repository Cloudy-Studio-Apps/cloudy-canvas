# Updates and releases

_How it works. The rules are in the root [CLAUDE.md](../../../../CLAUDE.md); names may still follow the pre-refactor conventions until their phase (see its Transition table)._

## Updates and releases

- **Updates and releases:** `AppUpdater` (`shared/core/app-updates/`: `installKind()`, `check()` → `AvailableUpdate` with `install(onProgress)`; `appUpdater` in `@platform`, `null` outside Tauri) wraps Tauri's updater (`plugins.updater` in `tauri.conf.json`: the public key and `releases/latest/download/latest.json` on GitHub; `tauri-plugin-process` restarts an AppImage). The Rust `install_kind` command (`src-tauri/src/install_kind.rs`) says `installer` (Windows NSIS, the macOS app), `appimage` or `package` (.deb, pacman: Update opens the release page instead, `releasePageUrl`). `useUpdateStore` (`shared/stores/update-store.ts`, never in dev builds) checks and installs, after `appLifecycle.runQuitTasks()` flushes pending saves; `AppUpdates` (`shared/app-updates/`, mounted in the providers) checks 5 s after start and every 6 h and shows `UpdateNotice` (bottom-left), and `CheckUpdatesButton` is in the About dialog and Settings. **About:** `AboutDialog` (`shared/about/`, mounted in the providers, opened with `openAbout()` from Home's wordmark, the board's logo, the design's main menu and Settings › About): logo, version (`useAppInfo`, `versionDetails`), license (AGPL-3.0), disclaimer and credits (`about-content.ts`). **Releases:** `pnpm release:tag <version>` (`scripts/release-tag.mjs`) writes the version into `package.json`, `tauri.conf.json`, `Cargo.toml` and `Cargo.lock`, commits, tags `v<version>` and pushes; `.github/workflows/release.yml` then builds the NSIS installer, a universal macOS `.app`/`.dmg` (`macos-latest`, `universal-apple-darwin`, signed ad hoc by `bundle.macOS.signingIdentity: "-"`, not notarized; the README tells users how to open it), the .deb and AppImage (Ubuntu 22.04) with `tauri-action` (`--config src-tauri/tauri.release.conf.json` turns on `createUpdaterArtifacts`, signed with the `TAURI_SIGNING_PRIVATE_KEY` secret, plus `latest.json`) and the Arch package (an `archlinux` container running `pnpm release:arch`) into a draft release, published by hand.
