# Updates and releases

_How it works. The rules are in the root [CLAUDE.md](../../../../CLAUDE.md)._

## Updates and releases

- **Updates and releases:** `AppUpdater` (`shared/core/app-updates/`: `installKind()`, `check()` → `AvailableUpdate` with `install(onProgress)`; `appUpdater` in `@platform`, `null` outside Tauri) wraps Tauri's updater (`plugins.updater` in `tauri.conf.json`: the public key and `releases/latest/download/latest.json` on GitHub; `tauri-plugin-process` restarts an AppImage). The Rust `install_kind` command (`src-tauri/src/install_kind.rs`) says `installer` (Windows NSIS, the macOS app), `appimage` or `package` (.deb, pacman: Update opens the release page instead, `releasePageUrl`). `useUpdateStore` (`shared/stores/update-store.ts`, never in dev builds) checks and installs, after `appLifecycle.runQuitTasks()` flushes pending saves; `AppUpdates` (`shared/app-updates/`, mounted in the providers) checks 5 s after start and every 6 h, shows `UpdateNotice` (bottom-left, `NoticeCard`: the first change of the update's notes, Update, What's new, Later) and `UpdatedNotice`, and hosts `WhatsNewDialog`; `CheckUpdatesButton` and `ChangelogButton` are in the About dialog and Settings. **About:** `AboutDialog` (`shared/about/`, mounted in the providers, opened with `openAbout()` from Home's wordmark, the board's logo, the design's main menu and Settings › About): logo, version (`useAppInfo`, `versionDetails`), license (AGPL-3.0), disclaimer and credits (`about-content.ts`). **Releases:** `pnpm release:tag <version>` (`scripts/release-tag.mjs`) runs the changelog check, fails when there's nothing unreleased, dates the unreleased sections of both changelogs as the version (a new, empty one goes above), writes the version into `package.json`, `tauri.conf.json`, `Cargo.toml` and `Cargo.lock`, commits, tags `v<version>` and pushes; `.github/workflows/release.yml` then builds the NSIS installer, a universal macOS `.app`/`.dmg` (`macos-latest`, `universal-apple-darwin`, signed ad hoc by `bundle.macOS.signingIdentity: "-"`, not notarized; the README tells users how to open it), the .deb and AppImage (Ubuntu 22.04) with `tauri-action` (`--config src-tauri/tauri.release.conf.json` turns on `createUpdaterArtifacts`, signed with the `TAURI_SIGNING_PRIVATE_KEY` secret, plus `latest.json`) and the Arch package (an `archlinux` container running `pnpm release:arch`) into a draft release. The draft's description, and `releaseBody` (the `notes` in `latest.json`), come from `scripts/changelog/release-notes.mjs <version>`, which fails the run before any build when the changelogs have no changes for the version. The `publish` job needs every build: when all passed it publishes the release (and installed apps see the update); a failed build leaves the draft, and re-running the failed job publishes it once it passes.

## Changelog

- **Files:** `CHANGELOG.md` (English) and `CHANGELOG.es.md` (Spanish) at the root, written for users (CLAUDE.md rule 31). After a title and an introduction, each `## ` is the unreleased section (`## Unreleased`, `## Sin publicar`, always first) or a version (`## 0.5.0 - 2026-11-02`); each `### ` a kind of change, only `New`/`Improved`/`Fixed` (`Novedades`/`Mejoras`/`Correcciones`, `CHANGELOG_HEADINGS`); each `- ` one change, plain text with `code` spans, indented lines continuing it.
- **Parsing** (`changelog/`, plain TS): `parseChangelog(text, locale)` gives the entries and the problems; `releaseNotesBody` writes a release's notes (the English groups, then `<!-- lang:es -->`, `## Español` and the Spanish ones) and `parseReleaseNotes(notes, locale)` reads them back in the app's language, English when it isn't there. Its files import each other with `.ts` because `scripts/changelog/` runs them with Node (which strips the types, so they hold only erasable TypeScript).
- **Checks:** `scripts/changelog/check-changelog.mjs` (in `pnpm lint`, `pnpm check:changelog` alone) reports lines it can't place, a missing or misplaced unreleased section, released versions without changes, emojis, and a translation whose versions or number of changes per kind differ from English.
- **In the app** (`shared/app-updates/`): `bundledChangelog()` parses the bundled file of the app's language (`?raw` imports; the unreleased section only in dev builds). `WhatsNewDialog` (`useWhatsNewStore`, `openWhatsNew` in `shared/stores/`) shows either one version's changes (`{ kind: "update" }`) or every version (`{ kind: "history" }`, from `ChangelogButton`). `UpdatedNotice` shows once after an update: `useLastSeenVersionStore` (`cloudy-canvas:last-seen-version`) remembers the last version seen; a first start, or a version the changelog doesn't list, only stores it.
