# Themes

_How it works. The rules are in the root [CLAUDE.md](../../../../CLAUDE.md)._

## Themes

- **Themes** (`shared/core/themes/`, plain TS): a `ThemeDefinition` (`id`, `label`, `appearance` light/dark, `extends`, `tokens` (the semantic tokens, `THEME_TOKEN_NAMES`), `products` (tokens inside `[data-product="<id>"]`, the design's canvas), `fonts` (`sans`/`mono` stacks, `--theme-font-*`), `density` (`compact`/`default`/`comfortable`: `DENSITY_METRICS`), `corners` (clamped to 8px), `preview`) lists only what it changes; `resolveTheme` merges its chain over the base (`cloudy-light`, `BASE_THEME_ID`) and `themeCss(resolved, scope, density?)` writes it (`html:root`, stronger than tokens.css, or a class scope). Built-ins (`presets/`, `BUILT_IN_THEMES`, light/dark pairs by family): Cloudy Light/Dark, Sand and Lilac (Cloudy tinted with the board's and design's scales), Orange (warm cream, tangerine), Black (true black for OLED, white buttons), High Contrast Light/Dark, Paper (sepia), Solarized Light/Dark, Catppuccin Latte/Mocha, Rosé Pine Dawn/Rosé Pine, JetBrains Light/Dark (IDE grays, `@fontsource-variable/jetbrains-mono`, compact), Nord, Dracula, Gruvbox Dark and Terminal (green phosphor, JetBrains Mono for the whole UI, compact, square corners); the published palettes use their schemes' own colors. `themeRegistry` (`ThemeRegistry`: `register(def, owner)`, `drop(owner)`, `list`, `get`, `subscribe`) is app-level like the sticker catalog; plugins add to it with `api.themes.register` (`app/plugins/plugin-themes.ts`: checked by `readThemeDefinition`, staged, committed when `activate` succeeds, dropped when it fails; `PluginStatus.themes`). The choice is `shared/stores/theme-store.ts` (`mode` `fixed`/`system`, `themeId`, `lightThemeId`/`darkThemeId`, a `density` override; migrated from the old `preference`). `shared/ui/theme/`: `activeTheme`/`useActiveTheme` (a missing theme falls back to the built-in of its appearance), `useThemes`, `useThemeMetrics` (px sizes: the layers list's rows), `onThemeChange`, `ThemeMenu` (Home's top bar, `/design-system`) and `themeChoices` (the design's main menu Theme group). `app/theme/` `ThemeSync` (in the providers, rendered after plugins load) writes `<style id="cloudy-theme">` (`applyTheme`: the theme, plus the base theme under `.theme-export-scope`), sets `data-theme`, `data-appearance` and `.dark` (Tailwind's `dark:`), caches the CSS (`THEME_CSS_KEY`), which `index.html` injects before first paint. Settings › Appearance (`pages/settings/sections/appearance/`) picks themes (cards with `ThemePreviewPicture`), Match system and the density. Density tokens: `--control-h`/`-sm`/`-lg`, `--control-px`, `--row-h`, as Tailwind spacing (`h-control`, `h-control-sm`, `size-control`, `px-control-x`, `h-row`; `cn` knows them); the shadcn button, input, select and tabs use them. Content colors (stickies, fills) never follow the theme.
