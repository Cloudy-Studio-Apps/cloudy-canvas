# Board colors

The board's named color variables: shapes' colors bind to them and follow them, with one mode per axis for the whole board.

- **Tier:** feature
- **Requires:** —
- **Contributes:** boardCanvas: `afterEdit`; boardEditor: `sidePanels`, `topBar`; `boardMcpTools`
- **Points it owns:** —
- **MCP tools:** `bind_board_colors`, `create_board_color_collection`, `create_board_colors`, `delete_board_colors`, `export_board_colors`, `import_board_colors`, `list_board_colors`, `set_board_color_mode`, `unbind_board_colors`, `update_board_colors`
- **Files:** `colors.module.ts`, `mcp/`, `ui/` (the colors panel and top-bar button).

## How it works

- **Board colors** (the `colors` module, phase 6 of the variables spec): boards bind colors only, to the same color variables as designs (`canvas/tokens/`). Kinds' `bindable` (`colorField`, `products/board/tokens/`): a sticky's, text's, pen stroke's (not a highlighter's), connector's and section's `color`, a geo shape's `fill` and `stroke`, a table's header `color` and each cell's `fills.<row>.<column>` (`moveCellBindings` moves them with `insertLine`/`removeLine`/`moveLine`; `bindCells`). The module's `afterEdit` is `syncTokens` with `BOARD_TOKEN_CONTEXT` (no modes per element: each axis's `current`, the whole board's mode). Color bars bind through tool options: each color option has a sibling `<option>Token` (`stickyColorToken`, `shapeFillToken`, …; `null` unbound), the field maps are the defaults' `colorOptions` (field → option), kinds' `restyle`/`optionsOf` use `restyleColors`/`colorTokenOptions` (binding writes only `bindings`, the sync writes the color) and the creating tools `newColorBindings`. UI: `BoardColorPalette` (`ui/components/board-colors/`: `DocumentColorsButton`, a `VariablePicker` with "Manage board colors…", then the `ColorPalette` (`noneSelected` while bound); `useBoardColor(option)`, `boardColorValue`) in the sticky, shape, section, connector, table and marker bars, and the table cell fills; the side panel `BoardColorsPanel` (`colorsOpen` in `board-panel-store`, the top bar's `ColorsButton`): `BoardModes` (a `SegmentedControl` per axis with two modes or more), each collection's colors in group accordions (`ColorRow`: `ColorValuePopover` edits the shown mode's value (`colorMode`) and the description (the row's tooltip), the name, follow another color (an alias) or stop, delete, `DeleteColorDialog` when used; collections and groups renamed with `InlineRename`, a collection deleted with its colors, `DeleteCollectionDialog` when it has some; empty ones show; the header's `AddMenu`: New color, New collection), `ColorsExchangeMenu` (import a `.cdesign`, `.cboard` or tokens JSON: `readColorSource` → `colorTokensOnly` (`canvas/tokens/exchange/`: color variables with their collections, axes and shade generators; aliases to what's left out dropped), `ImportColorsDialog`; export DTCG or CSS). Agents (`colors/agent/`): `list_board_colors`, `create_board_colors`, `update_board_colors`, `delete_board_colors`, `create_board_color_collection`, `bind_board_colors` (`field` defaults to the shape's first), `unbind_board_colors`, `set_board_color_mode`, `import_board_colors`, `export_board_colors`; `list_shapes`/`get_selection` summaries carry `colors` (`boundColors`).
