# Board editor

_How it works. The rules are in the root [CLAUDE.md](../../../../CLAUDE.md); names may still follow the pre-refactor conventions until their phase (see its Transition table)._

## Board editor

- **Board editor (`products/board/ui/`):** `BoardEditorPage` (`/board/:id`) loads the document and mounts the engine with `getBoardProduct()`. `BoardSession` provides the engine, the file and `getBoardEditorModules()`, and renders `ModuleSession` and `BoardChrome`, which places the module slots. Panels read the schema with `useBoardSchema()` (the `DB_SCHEMA` service) and `useDbQuery`/`useDbTable`/`useDbEnum` (`modules/db/ui/schema/`), which re-read only when the schema changes. The database panel (`modules/db/ui/db-panel/`, with the shared DBML `ui/components/source-editor/`: `SourceEditor` applies text while typing, shared with the ER panel's Text tab, and colors it with the `languages/` `dbmlLanguage` and `erLanguage`, small `StreamLanguage`s that never fail on half-typed text, and suggests with `completions/`: `dbmlCompletions` (keywords, column types and enums, settings, `table.column` ref targets, from the board schema plus names the text defines) and `erCompletions` (keywords, settings, the diagram's entity and relation names)) shows the selected table or enum (`selectedId` + `selectionTypes` from `EngineState`), or the whole schema from the top bar's button (`modules/db/ui/schema-button.tsx`, state in `ui/stores/board-panel-store.ts`); `.dbml` import/export goes through `@platform`. The ER panel (`modules/er/ui/er-panel/`) works the same way with the board's `ErModel` (`useErModel` is the `ER_MODEL` service; `useErQuery`, `useErSelection` in `modules/er/ui/model/`): it opens when an ER element is selected and shows that element's diagram, as a form for the selected element or as text. Board components that read or set tool options use `useBoardEngine()` / `useBoardState()` (`board-engine-context.ts`), typed with `BoardToolOptions`. The tool options panels (in each module's `ui/`) are contributed to `toolPanels`/`selectionPanels`.

- **Board modes:** a board mode is one `defineBoardMode({…})` object registered with `registerBoardMode(host, mode)` (`ui/modules/`), `canvas-ui`'s `registerEditorMode` with the board's points (the ER mode).
