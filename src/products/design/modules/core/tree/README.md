# The layer tree

_How it works. The rules are in the root [CLAUDE.md](../../../../../../CLAUDE.md); names may still follow the pre-refactor conventions until their phase (see its Transition table)._

## The layer tree

- **The layer tree** (`modules/core/tree/`): nodes store `parentId`; coordinates stay in world units. The core module gives the canvas `treeOrderKeys` (parents draw before their children, siblings by `index`), `withDescendants` (`withMembers`: a frame moves and deletes with what it holds), `reparentMoved` (`onMoved`: a dropped node goes into the topmost visible container under its center, `containerAt`) and `prepareTreeCopies`. `DESIGN_TREE` (`DesignTree`: `layers()`, `node`, `ancestors`, with `subscribe`/`getVersion`) is what the Layers tab reads. **Moving layers** (`core/tree/move/`) is one place for every caller: `moveIntoProblem(node, parent, kinds, byId)` is the rule set (the parent holds layers, `holdsLayers`: a `container` or a `childHost`; `canGoInto`; same page; not into itself), `LayerDestination { parentId, position }` (topmost first among the children that don't move), `layerChildren`, `layerDestinationAt(elements, id, "above" | "below" | "inside")`, `placeLayers` (indexes between the neighbours, order kept), `layerMovePatches` (checked) and `moveLayers(doc, kinds, ids, destination)` (writes them and prunes emptied groups and booleans; the caller makes the undo step). `checkParent` (agents' `parent`/`parentId`), `reparentMoved` (canvas drops) and the agents' `move_layers` (`layers/move-layers.agent-tool.ts`) use it. The Layers tab (`layers/ui/`) is a flat list of `visibleRows` (`LayerRowItem`; opened layers plus the selection's ancestors) drawn with `useVirtualList` (`shared/ui/hooks/`, fixed 28 px rows, `LAYER_METRICS`) and memoized `LayerRow`s; `drag/` drags rows Figma's way: `layerDrop` (pure: a row's top/bottom quarter drops above/below it, the middle into a layer that holds others, below an open layer is its top child, moving left below a last child goes out a level; refused places show nothing), `useLayerDrag` (pointer-based past `MOVE_THRESHOLD_PX`, drags the selection or the pressed row, scrolls at the edges, opens a closed layer held over, Esc cancels, one undo step) and `DropIndicator` (the line and a ghost label).
