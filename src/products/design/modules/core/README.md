# Design core

What every design has whatever its other modules: the node base and the layer tree, paints and strokes, the move, scale and hand tools, the properties panel's shared sections, styles' controls, the main menu and the agent tools that work on any layer.

- **Tier:** core
- **Requires:** —
- **Contributes:** designCanvas: `alignTarget`, `clips`, `drawOrder`, `frames`, `hostCommands`, `keybindings`, `layerTree`, `onMoved`, `pasteOnto`, `prepareCopies`, `resolveElements`, `rootOf`, `rulerFrame`, `selectTarget`, `undrawn`, `view`, `withMembers`; designEditor: `contextMenu`, `mainMenu`, `modes`, `overlays`, `propertySections`, `sessionHooks`, `toolSidebars`, `tools`; `designMcpTools`, `designStyleTypes`
- **Points it owns:** `designStyleTypes` (`ui/core.points.ts`): the kinds of style in the Styles section; core gives color and stroke, text and effects theirs, plugins more. `designStarters` (`ui/core.points.ts`): Home's ready-made starts for a new design (`DesignStarter`, a `CanvasStarter`), run on a new file by the `start-starter` session hook (`useDesignStartStarter`) when its link has `?starter=<id>`; frame and catalog give theirs, plugins more
- **File tools:** `file_get`, `file_info_set` and `file_save`, shared with boards; listing, opening and creating files are the app-level `file_recent_list`, `file_open` and `file_new` (`canvas/mcp/files.mcp.ts`).
- **MCP tools:** shared with boards (the description and arguments in `canvas/mcp/shared/` or the `canvas/mcp` factories, the design's `run` here): `file_get`, `file_info_set`, `file_save`, `selection_get`, `selection_set`, `history_undo`, `history_redo`, `view_fit`, `view_fit_elements`, `view_snapshot`, `clipboard_png_copy`, `arrange_align`, `arrange_distribute`, `arrange_tidy_up`, `arrange_scale`, `style_copy`; the design's own, still under the transitional `design` prefix: `create_nodes`, `delete_nodes`, `duplicate_nodes`, `export_nodes`, `flip_nodes`, `get_nodes`, `list_nodes`, `lock_nodes`, `reorder_nodes`, `rotate_nodes`, `update_nodes`
- **Files:** `core.canvas.ts`, `core.commands.ts`, `core.sections.ts`, `core.menu.ts` (wiring), `node/` (`DesignNodeKind`, paints, strokes), `tree/` (the layer tree's hooks), `styles/` (paint, stroke and effect style data), `transform/`, `tools/`, `network/` (vector networks), `mcp/`, `ui/` (sections, styles UI, `core.points.ts`).

## How it works

What every design has whatever its modules: the canvas view (plain, pixel grid, 2%–25600%, size label, snapping) and the layer tree's hooks (`core.canvas.ts`), its commands (`core.commands.ts`), the move, scale (K) and hand buttons and the properties panel's shared sections (`core.sections.ts`; the Fills and Strokes sections are `PaintListSection`, a layer's paints with its style control, over `PaintStackSection`, any paint stacks with a color drag as one undo step; while areas of a vector are picked in its edit mode, `REGION_SELECTION` (`node/region-selection.ts`, read with `useRegionSelection`), the Fills section is `RegionFillSection`, those areas' own fills with "Use layer fill" (dropping what was bound on them); one area also takes a color style, variables on its colors and its gradient's handles on the canvas), the main menu (`core.menu.ts`), color and stroke styles, and the agent tools that work on any layer (reading, creating and editing through the kinds, arranging, viewing, exporting, files).
