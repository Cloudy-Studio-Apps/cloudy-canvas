# Styleguide (Design module)

_How it works. The rules are in the root [CLAUDE.md](../../../../../CLAUDE.md); names may still follow the pre-refactor conventions until their phase (see its Transition table)._

## Design system

- **Design system** (`styleguide/`, phase 3 of the variables spec; **everything is in this one folder**, user): the file's variables and styles drawn as a style guide that stays up to date. A **live element** is a frame with a `sheet` field (`TokenSheet`: `category`, `group?`, `template` (`null`: the configured one), `options`, `modeView` `current`/`all`, `hash`), whose children are real layers marked `generated: { sheet, key }` and `locked` (fields the module reads with its own guards, `isSheet`, `generatedMark`; core types don't know them). The module's `afterEdit` (`system/sync-styleguide.ts`, gated to edits touching tokens, the title (`EditedChange.meta`), modes, sheets or the system page) keeps the **system page** (`ensureSystemPage`: a page with `hidden: true` and `styleguide` settings (`StyleguideSettings`: category `order`, `hidden` categories and groups, template `choices` by `"cat"`/`"cat:group"`, the view's `modeView`), made in the step of the file's first variable or style and removed with its last, holding one sheet per non-empty category, stacked by `stackSystemSheets`), then builds each relevant sheet's content as agent-style node specs (`buildSheet`: a heading, then a section per group (`sectionKey`), each its template's body, per mode side by side with `modeColumns`; `sheetContext`), hashes it (`hashText`) and only when it changed reconciles it into the sheet's children by key (`reconcileSheet`: built through `kind.buildNode`, patched with what differs, never writing positions, hugged sizes or bound fields, which auto layout and the token sync own; a spec that doesn't build is skipped). Looking never writes. **Points** (`styleguide-points.ts`): `styleguideCategories` (`StyleguideCategory`: `id`, `label`, `order`, `groups(store, doc)` → `SheetGroup`s of `SheetItem`s, `defaultTemplate`, `untitled`; built-ins in `categories/`: cover, colors, typography, spacing, radius, effects, strokes, paint styles, opacity, other) and `styleguideTemplates` (`StyleguideTemplate`: `id`, `category`, `label`, `description`, `options` (`TemplateOptionSpec`: boolean, number, select, font), a pure `build(group, options, context)` → `GeneratedSpec`s; built-ins in `templates/<category>/`, made with the spec builders `stack`, `box`, `dot`, `label`, `solidFill`; swatches bound at `fills.0.color`, samples at `textStyle`/`fills`/`effects`/`strokeStyle`, numbers at `w`/`cornerRadius`/`strokeWeight`/`opacity`); `templateChoice` resolves element → group override → category default → built-in default. `DESIGN_STYLEGUIDE` (`DesignStyleguide`, `model/`) is the only place that edits settings and live elements (`setOrder`, `setHidden`, `setChoice`, `setModeView`, `setSheet`, `addSheet`, `convert`: `convertSheets` sets `sheet`/`generated` to `null` and unlocks, keeping bindings; the system page's sheets can't be converted). **Mode** `styleguide` ("Design system", always in the switcher): isolates the system page's sheets, `StyleguideTool` selects without moving, `STYLEGUIDE_ALLOWED_COMMANDS`; `useStyleguideScope` shows the system page while it's on and goes back after (the page shown outside the mode turns it on), `StyleguideEmpty` shows without tokens. UI: the Design system left tab (`ui/tab/`: categories and groups, show/hide boxes, drag to reorder, click to show), the mode sidebar (`StyleguideSidebar`: `TemplatePicker` of `SelectableCard`s with `SpecPreview` thumbnails (the specs drawn as DOM, `useSheetPreview`), `TemplateOptions`, modes side by side, Export as PDF), the live element's properties section (`SheetSection`: source, template, modes, Convert to design), the `token-sheet` tool (Shift+D, the toolbar's frames menu, `TokenSheetTool`), the selection's "Design system" submenu (export the section through the export dialog, export the whole system as one PDF (`exportSystem`, a page per section), Add to page, Convert to design) and the main menu's "Design system". Clicks on generated layers select their sheet through core's `designSelectRedirects`. Agents: `get_design_system`, `set_system_template`, `add_system_element`, `convert_system_element` (`agent/`); generated layers edited by other tools are rebuilt.
