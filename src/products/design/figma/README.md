# Figma import

_How it works. The rules are in the root [CLAUDE.md](../../../../CLAUDE.md); names may still follow the pre-refactor conventions until their phase (see its Transition table)._

## Figma import

- **Figma import** (`figma/`, outside the `@design` barrel: loaded only by `import("@design/figma")` in `importFigmaFile`, `ui/file/`, with `fflate` and `fzstd`; reading and converting run in a worker, `figma-import.worker.ts` via `convertFigmaFile`, which reports progress; `figmaDesignDocument` then adds everything in one transaction, `doc.addAllUntracked`; callers use `importFigmaWithLoading`, which shows the global loading screen): `.fig` files ("Save local copy…") opened, dropped or picked in Home's open dialog (`isFigmaPath`/`isOpenablePath` in `shared/core`, `openCanvasFileDialog({ figma: true })`) become a new design draft named after the file. reading the file is shared with FigJam's import in `src/canvas/figma/` (`@canvas/figma`, a deep import outside the `@canvas` barrel so `fflate`/`fzstd` stay lazy): `kiwi/` decodes Kiwi by interpreting the schema the file carries (no generated code), `container/` (`readFigFile`) unzips, reads the prelude (`kind`: `fig-kiwi` is `design`, `fig-jam.` is `figjam`; Slides are refused) and inflates the chunks (deflate or zstd), `nodes/` holds the node types, `buildFigTree`, the matrices, `FigImportContext` (blobs, images as assets, `ImportWarnings`) and `worker/` runs an import in a worker (`runFigmaWorker`, `serveFigmaWorker`); `convert/` (`convertFigma`) builds the node tree by guid (`buildFigTree`, siblings by position), expands instances (`resolveFigNode`: the component's nodes with `symbolOverrides`, `derivedSymbolData` and text/visibility properties by guid path, nested instances included), turns the file's variable collections, variables (values by mode, aliases, scopes, code syntax) and shared styles (text, color, effect) into tokens (`convert/tokens/`: `figVariables`, collections keeping Figma's modes so the variables module's migration makes the axes; `figStyles`; ids by guid in `FigImportContext.setTokenId`/`tokenId`/`styleId`, values `tokenValue`, so a paint bound to a variable that doesn't vary by mode shows the variable's color, as Figma draws it (overrides keep a stale one); frames' and pages' picked modes, `variableModeBySetMap`, come as `variableModes`, `figVariableModes`) and binds layers to them (`withFigBindings`: paints' `colorVar` by converted index, `convertPaintsFrom`; `variableConsumptionMap` fields, `figLayerBindings`; text, color and effect styles; ranges' text styles; kept where the kind offers the path), applies the shared styles each node uses (`withFigStyles` in `canvas/figma/nodes/`: a text style's typography, color styles' fills and strokes, an effect style's effects, found by guid or library key with `FigTree.style`; the style wins over the node's own values, which plugin-written files leave stale), and maps nodes to elements in world coordinates (`convertChildren`): pages, frames (components and instances), groups, sections, box shapes, lines, vectors (the network blob is Figma's model, with the transform applied), texts (first style), booleans (live, their operation mapped: XOR is exclude, operands converted as children). Skewed shapes and unknown layers become vectors of Figma's precomputed outline (`pathToNetwork`); gradients keep their stops and transform; what was lost is counted (`ImportWarnings`) and shown in a toast. Prototype and Dev Mode data are ignored.
