# Design editor

_How it works. The rules are in the root [CLAUDE.md](../../../../CLAUDE.md)._

**Public API.** `ui/index.ts` (`@design/ui`) is the editor's public API as well as its entry: `ui/components/panel` (all of it), `ui/hooks`, `useDesignEngine`/`useDesignState`, `useImageCropStore`, `ui/modules` (points, mode helpers, section filters). Built-in modules import those pieces by their path (importing `@design/ui` from a module would loop through the module list), and plugins get them as `api.design`, with the engine barrel. `scripts/check-public-api.mjs` fails when a feature imports a piece this barrel doesn't export.

## Editor

- **Editor** (`ui/`): `DesignEditor` mounts the engine in a container between the docked panels (`design-layout.ts`, `canvasInset`: the rail, the left panel while `leftOpen`, the properties panel while `rightOpen` (`design-panel-store`, persisted; the rail's bottom button, the properties header's hide button and `ShowPropertiesButton` over the canvas's top right, the `toggleLeftPanel`/`toggleRightPanel` host commands in the main menu), nothing with the UI hidden; `useCanvasInset`, and `useKeepCanvasInPlace` pans with `engine.panBy` so the content stays put when the edge moves; `data-product="design"` for the canvas tokens) that never remounts; `DesignSession` provides the engine, `CanvasFileContext` and the modules; `DesignChrome` places `DesignRail` (main menu + `leftTabs`, the agents menu above its panel toggle), `LeftPanel` (file name, the active tab), `PropertiesPanel` (history, collaborators, Share, Design/Prototype tabs of `propertySections`, `ZoomMenu`) and, laid exactly over the canvas, the context menu, `ModuleSession` and the toolbar. Panels read the selection with `useSelectedNodes` (over `useSceneElements`, which hears changes at most once per animation frame) and write through `useEditNodes`/`useMoveNodes` (`ui/hooks/`, one undo step each); their building blocks are `ui/components/panel/` (`PanelSection`, `PropertyGrid`, `FieldBox` (the compact field's look), `NumberField`, `HexInput`, `PercentInput`, `PaintField`, and the fields bound to the selection, `NodeNumberField`, `NodeSelectField`, `NodeCheckbox`: `read(node)`/`patch(value)`, "Mixed" through `sharedValue`, one undo step). Section `when`s use `ofType(...types)`, `allKinds(can)`, `someNodes`, `noNodes` (`ui/modules/section-filters.ts`). A `PaintField` edits a whole paint (solid, gradient or image), so it isn't `canvas-ui`'s `ColorField`, which edits a color. Its swatch opens `PaintPicker` (`ui/components/paint-picker/`, Figma's paint picker): tabs per paint kind (Solid, Linear, Radial, Angular, Diamond and Image work; Pattern is disabled for now; strokes can't be images; switching to a gradient starts it as Figma does, `gradientPaint`), `ColorControls` (shared by solid paints and gradient stops), `SolidEditor` (the `canvas-ui` color controls in `components/color/`: `SaturationArea`, `ColorSlider` for hue and opacity, `EyedropperButton` where the browser has one, `hexToHsv`/`hsvToHex`; hex and opacity fields; "On this page" and "Recent" swatches, `paint-recents-store`) `GradientEditor` (`GradientStopBar`: click adds a stop, drag moves one (Shift: 5% steps), drag it off or Delete removes it; the selected stop's `ColorControls` and its blend to the next (`StopEaseSelect`); `GradientToolbar`: copy as CSS, smooth blending (OKLab), rotate 90°, reverse, add a stop; the stop list (`GradientStopRow`); "On this page" (`pageGradients`) and "Recent" gradients) and `ImageEditor` (Fill/Fit, a preview through `useAssetUrl`, "Choose image…", `canvas-ui`'s `ImageChooseButton`). A drag in the picker reports `{ done: false }` steps, which `useEditNodes(…, { checkpoint: false })` joins into one undo step. While the picker is on a gradient of one selected layer (`gradient-edit-store`: the paint, by field and index, and the selected stop), the core module's `GradientHandles` overlay (`modules/core/ui/gradient-handles/`) draws its handles over the layer, Figma's way (linear: start and end; radial, angular and diamond: center, radius and width; the stops along the line), and drags them (`dragGrip`; Shift snaps to 15°). The core module's sections: Page, Position (align, X/Y counted from the corner of the container each layer is in, `layerPosition`/`positionMove`, as in Figma (in a mirrored container from its right edge); agents keep world coordinates), Layout (W/H, keep proportions, swap them: portrait ↔ landscape), Appearance (opacity, corner radius when every node has one), Fills, Strokes, Export, and the Prototype placeholder. Tab state is `ui/stores/design-panel-store.ts` (persisted).
