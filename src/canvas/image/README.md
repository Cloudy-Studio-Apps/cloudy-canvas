# Images in a box

_How it works. The rules are in the root [CLAUDE.md](../../../CLAUDE.md)._

## Images in a box

- **Images in a box** (`canvas/image/`, plain TS): an `ImageTransform` is Figma's `imageTransform` (2×3, the layer's normalized box → the picture's), an `ImageCrop` the axis-aligned case (`cropTransform`/`transformCrop`), `ImageRotation` quarter turns and `ImagePlacement` what the renderer takes (`contain`/`cover` with a rotation, `transform`, `tile` with a scale). Helpers: `fitTransform` (the transform that looks like contain/cover), `imageQuad`, `panTransform`, `zoomTransform`, `reframeTransform` (the box changes, the picture stays), `rotateTransform90`, `clampCrop`, `cropInside`, `coverCrop`. `ImagePaintLayer.placement` is drawn by `PaintStack`'s image slot (a sprite placed with `imageMatrix`, or a `TilingSprite` whose tiles use the picture's own size, `ImageCache.naturalSize`); `view.placeImage(assetId, box, fit | crop)` crops the texture's frame (`fitImage`). `ImageCropOverlay` (`canvas-ui/components/image-crop/`, pure drag math in `crop-drag.ts`) edits one: the picture dimmed past the box, drag to move, its corners scale it (Alt: round its middle), the box's sides resize the element (Shift keeps the ratio), Enter/Esc finish; `clamp` keeps the crop inside the picture. Overlays map boxes to the screen with `canvas-ui/overlay/` (`normalizedToScreen`, `screenToNormalized`, `screenToLocal`, `useViewMapping`; an `OverlayFrame` with `mirrored` maps in the frame of what a mirrored element draws, so crop and gradient handles sit on the mirrored picture), and `useAssetUrl` shows an asset in the DOM.
- **Animated GIFs** (`gif/`): `parseAnimatedGif` reads a file's frames without decoding their pixels (`null` for anything else, a GIF of one frame, or one over 4096×4096 pixels, which stays a still; a file cut short keeps its whole frames); `isAnimatedGif` says whether a file moves. `decodeGifFrame` decompresses one frame's LZW data into color indices (also interlaced ones; broken data leaves the rest of the frame at index 0), and `GifPlayer` lays frames over each other on an `OffscreenCanvas` as they're reached, following each frame's disposal, its transparent color and its delay (10 ms or less counts as 100 ms, as in browsers), and loops forever whatever the file says. It's our own decoder rather than `ImageDecoder`, which WebKit (the desktop app on Linux and macOS) and some browsers opening a board's HTML export can't be relied on for. `GifPlayback` (`canvas/render/`) drives it.
- **Placeholder pictures** (`placeholder-svg.ts`, `placeholder-ink.ts`): `placeholderSvg(background, size, { label? })` is the foca watona with a "?" on `background` as an SVG file, its ink darkened or lightened from the background (`placeholderInk`); `label` writes a line under it. The design's image placeholders and the board's HTML export (plugin elements it can't draw) use it.
