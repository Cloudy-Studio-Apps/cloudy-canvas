# Paths

_How it works. The rules are in the root [CLAUDE.md](../../../CLAUDE.md)._

## Paths

- **Paths** (`canvas/path/`, plain TS): a `PathShape` is contours of cubic `PathSegment`s (`PathContour { start, segments, closed, hole? }`; a closed contour's last segment ends at its start). `booleanPaths(op, operands)` (`union`, `subtract`: the first minus the rest, `intersect`, `exclude`; each `PathOperand` filled by its own `fillRule`) and `normalizePath(shape, fillRule)` (overlaps and self-crossings resolved into outers followed by their holes) run Clipper2 (`clipper2-ts`) on flattened integer paths (`flattenContour`, adaptive to `FLATTEN_TOLERANCE`, ×`PATH_SCALE`) whose points carry `SourceTags` in `z` (the curve and `t` each came from; Clipper's Z callback tags crossings), so `rebuildContour` turns the result back into the source curves' exact parts (`subCurve`). `outlineStroke(shape, { width, cap, join, miterLimit })` is a stroke's area (`ClipperOffset`); `strokeArea(shape, { …, align, dashes, dashOffset })` lays it `inside`/`center`/`outside` (twice as wide, cut by what the closed contours enclose; open ones stay centered) after `dashPath(shape, pattern, offset)` (dashes as open parts of the source curves by arc length, an odd pattern repeated, the dash over a closed contour's start joined); `rectPath(rect, radius)` is a (rounded) box and `boxSidesStroke(w, h, radius, sides, align)` a box's band with a weight per side (`BoxSides`). Also `pathBounds` (exact curve extremes), `pointInPath` (even-odd over normalized contours) and `distanceToPath`, `placePath`/`localPath`/`mapPath`, the bezier helpers (`pointAt`, `splitAt`, `subCurve`, `flatness`, …) and `fillPath(g, shape, style)` (each outer filled, its holes `cut()`) / `strokePath`. `LruCache` and `identityKey` (`canvas/utils`) cache what's worked out from shapes.
