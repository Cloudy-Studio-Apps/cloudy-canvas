# Text and fonts

_How it works. The rules are in the root [CLAUDE.md](../../../CLAUDE.md)._

## TextEditor

- `TextEditor`: a DOM textarea overlay. Tools type a new element's text with `ctx.editNewText(draft)`: the draft is added to the document (and selected) only when the edit is committed with some text. An element with several texts (a table's cells) names each with a `part` key (`ElementText.partAt`/`partBox`/`nextPart`/`firstPart`): double-click edits the part under the pointer, Tab moves to the next, and only that part's text slot is hidden while editing.

## Rich text

- **Rich text** (`text/rich/`, `text/rich-editor/`): a text with styled ranges is `TextRun`s (`{ start, end, style }`, UTF-16 indexes, the style the product's; `normalizeRuns`, `spliceRuns`, `styleRuns`, `clearRunFields`, `runsForText` move and split them as the text changes) over styled `RichSpan`s, which `layoutRichText(text, spans, frame)` lays out (`RichTextLayout`: lines of fragments, words wrapping greedily across spans, a line as tall as its tallest span, every span on one baseline centered in its own line height, align and justify), measured with `measureSpan`/`spanOffsets` and `fontMetrics` (Pixi's, dropped by `fontsChanged` when a font loads; caches key on `fontsVersion()`, and the engine re-syncs the views using it). `ElementView.placeRichText(layout, alpha)` draws it into one canvas texture (`RichTextSprite`, `drawRichText`: fragments on their baselines, `decorationRect` underlines and strikethroughs; drawn white for `setPaintTextMask`). A kind with `ElementText.rich` (`RichTextSpec`: `runs`, `layout`, `apply`, `shortcut`) is edited by a `RichTextSession` instead of the textarea: a hidden textarea takes typing, IME and the clipboard (its value is the text), the canvas redraws the element as edited (`renderer.previewElement`, or the draft layer for a new one), the caret and highlight are DOM (`RichEditorOverlay`) from the same layout (`rich-caret.ts`: `caretRect`, `selectionRects`, `indexAt`, `wordRange`), clicks/drags/double and triple clicks select (`pointerSelect`), Up/Down/Home/End move by layout lines, Ctrl+B/I/U and Ctrl+Shift+X toggle styles, and the session keeps its own undo (`SessionHistory`), written as one document step when it ends. Focus moving to the app's controls keeps it open; `EngineState.textSelection`, `engine.editingText()` and `engine.styleTextRange(patch)` (on what's typed next with only a caret) are what panels use.

## Line heights below the font's own

- **Line heights below the font's own** center each line's glyphs in it as CSS and Figma do (they reach past the line): `ElementView.placeText` moves Pixi's text up by `negativeHalfLeading` (`render/text-leading.ts`; Pixi starts every line at its top) and aligns by the lines' height, and the design's glyph outlines (`textOutline`) place baselines the same way.

## Text and fonts

- **Text and fonts** (`text/`): text is shaped by a `TextFont` (`textFont(size, options)`: family, weight, style, line height, letter spacing; the app's Inter by default), which drawing (`canvasTextStyle`, `view.placeText`, alignment left/center/right/justify, top/middle/bottom), measuring (`measureTextBlock`; `measureText`/`measureWrapped` are its app-font shorthands) and the editor (`textEditorStyle`) share. An element's text sizing is `fitContent`, `fitHeight` or, per element, `text.sizing(el)` (`content`/`height`/`fixed`). Kinds name the faces their text uses with `fonts(el)` (`FontRequest`); the engine's `FontTracker` loads each once through `CanvasEngineOptions.fonts` (a `FontLoader`; `useCanvasEngine` passes `fontLibrary` from `@platform`), then redraws the elements using it (`ElementView.refreshText`) after their kind's `fontsLoaded(el)` patch (e.g. an auto-sized text's new size, outside the undo history). Fonts are `FontLibrary` (`shared/core/fonts/`: types, weights and names, `closestVariant`, Google catalog and CSS parsing): `platform/fonts/` lists installed families (the Rust `system_fonts` command) and Google's (`fonts.google.com/metadata/fonts`, cached a week, a short fallback list offline), and loads a Google face as `FontFace`s from its CSS, caching the files in `<appData>/fonts/`.
