# Copy and paste

_How it works. The rules are in the root [CLAUDE.md](../../../CLAUDE.md)._

## Copy and paste

- **Copy and paste** (`clipboard/`): `ElementClipboard` copies the selection with what moves with it (`withMembers(…, "move")`), as scene elements, to the system clipboard as JSON (`encodeClipboard`/`decodeClipboard`, tagged with the product id, with the assets they show in base64 so images paste into other files). `insertCopies` clones them (`cloneElements`: fresh ids and indexes, and `remapIds` rewrites every string equal to a copied id, so references between copies follow without knowing the types), runs the product's `prepareCopies`, offsets them with `kind.move` and adds them as one undo step. Pastes land 20 units further each time while the source is in view, otherwise centered in it. Elements copied from another product go through the product's `pasteForeign(el, from)` (the `pasteForeign` point; `decodeClipboard`'s `foreign`), and what none takes is left out (a foreign payload is never pasted as its JSON text, `isCanvasClipboard`). Anything else on the clipboard goes through `paste-external.ts`: an image (preferred over text) becomes an asset plus the product's `pasteImage` element, and text goes to `pasteText`. Files dropped on an open editor go the same way (`drop-files.ts`, `engine.dropFiles(files, clientPoint)`): images and SVGs through `pasteImage` (fit and centered on the drop point; SVGs are sized by `svgSize`), `.txt` files through `pasteText`, cascaded by a paste step, as one undo step. The system clipboard is the `Clipboard` interface (`shared/core/clipboard.types.ts`: text, plus `readImage()` as an encoded file; `platform/clipboard.ts`: Tauri's clipboard manager, whose RGBA images are encoded to PNG, or `navigator.clipboard` in the browser), passed as `CanvasEngineOptions.clipboard` by `useCanvasEngine`; without one, the engine uses a `MemoryClipboard`. The commands are `copy`, `cut`, `paste` and `duplicate` (Ctrl+D). Alt-dragging with the select tool duplicates in place (`ctx.duplicate`) and drags the copies.
